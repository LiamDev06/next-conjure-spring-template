# next-conjure-spring-template
A template with boilerplate setup for building Web applications with a Next.js frontend, SpringBoot backend and Conjure for API contract.
This is a setup I've started to like recently that I find myself often ending up with and therefore I wanted to publiclize my setup in a template.

- SpringBoot web starter, JPA repository as well
